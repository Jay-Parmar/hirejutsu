# Skills to look for in resumes, one per line: the name to show, then other
# ways people write it, separated by |. Matching ignores case and only counts
# whole words, so "java" is not found inside "javascript".
#
# A leading ! means that spelling only counts in exactly this case and as a
# word of its own. It is for names that are also plain English or a single
# letter: "Go" is a skill but "go" is not, and neither is the C in C-suite.
